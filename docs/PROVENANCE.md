# Scope and provenance

This standalone extraction contains two utilities from the OMINI project:
silhouette-based camera fitting and Blender rendering/compositing. It is **not**
the complete OMINI training or reconstruction pipeline and does not reproduce
all paper experiments by itself.

## Source lineage

- Camera fitting: `scripts/legacy_assets/optimize_camera_pose_combined.py`
  in the archived OMINI source snapshot dated 2026-08-25. The inspected local
  copy and archive member were byte-identical before extraction.
- Rendering: the 1,812-line revision-era `scripts/render_control_passes.py`.
  The archived 1,864-line variant additionally contained HSV comparison
  experiments; these experiments are not included here.
- OBJ import compatibility: the Blender 4.2 adaptation used in the later
  camera diagnostic, without its case registry or experiment orchestration.

The originals remain unchanged. This extraction replaces case registries and
server paths with explicit inputs, removes training/evaluation/API integration,
and introduces safer output handling and configurable Cycles devices.
It is a maintained utility extraction, not a byte-for-byte reproduction of
the historical experiment scripts. See the camera implementation for any
selection safeguards added during extraction.

## Extraction fixes

- Rasterize triangles as a **union**, one convex fill at a time. Passing all
  overlapping mesh triangles to a single `fillPoly` call uses an even-odd contour
  rule and can erase their interior coverage. The synthetic end-to-end check
  exposed this issue; duplicate/overlapping-triangle regression tests cover it.
- Rerank both retained coarse and refined candidates on the original mesh,
  rather than assuming a budget-limited local refinement must improve its seed.
- Compute the final reported silhouette score in the true full image frame.
- Use scale-relative distance and clipping limits; preserve existing imported
  materials and handle OBJ operator changes without a server-specific wrapper.
- Separate straight-alpha object compositing from the shadow-catcher opacity;
  add numerical tests for partial alpha and shadow/background isolation.

These fixes apply only to this standalone extraction. Historical source files
and historical experiment records were not changed or regenerated.

## Deliberately excluded

3D reconstruction services, SAM inference, SDXL/LoRA adaptation, diffusion
refinement, UV texture optimization, illumination estimation, HSL/VLM correction,
numerical experiment tables, user studies, GPU reservation scripts, private
datasets, checkpoints and historical execution logs.

Users supply a mesh/material, a mask in the original image coordinates, and,
when compositing is desired, a prepared background and optional HDR/EXR.
An input mask may be generated by any segmentation tool. Background inpainting
is outside this package.

## Distribution status

Prepared as a private review repository. No open-source license has been chosen
or granted by this packaging step. Confirm the authors' license choice and
rights to any example assets before changing repository visibility. The example
generator creates synthetic geometry/images locally; it does not redistribute
paper assets or third-party model weights.
